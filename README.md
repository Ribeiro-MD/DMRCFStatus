# DMRCFStats

Estatísticas dos meus mods no CurseForge: downloads, evolução, versões e lançamentos.

**Ver:** https://ribeiro-md.github.io/DMRCFStatus/

- `index.html` — a página (HTML, CSS e JavaScript, sem dependências)
- `historico.js` — registos dos downloads ao longo do tempo
- `recolher.py` — tira um registo novo dos mods em `mods.txt`; corre de 6 em 6 horas pelo GitHub Actions
